How it works

From folder to answers in three steps

1

Open a project

Pick a folder or paste a GitHub link. LogicLens reads the code with Tree-sitter, no setup needed.

2

Explore the map

Click a node to read its code, see what it calls and who calls it. Double-click to open that file.

3

Check a change

Run an impact analysis before editing a function and keep the report with the rest of your notes.

    Questions

    Quick answers

    Does my code leave my computer?
    The graph and search index are stored on your machine. Only the optional AI explanations and impact reports send the relevant code snippets to the AI provider you configure.
    Do I need an API key?
    The graph, views and search work without one. Explanations and impact reports need a key for Groq or Gemini, or a local Ollama model. Add it in the setup screen or in Settings.
    Which languages work?
    Python, JavaScript, TypeScript, Java, Kotlin, Go, Rust, C and C++, C#, Ruby, PHP, Swift, Dart, Scala, R, Julia, Vue, Svelte and Jupyter notebooks.
    Windows says the app is unrecognised
    The installer is not code signed yet, so SmartScreen may warn. Choose More info and then Run anyway.
    Can I build it myself?
    Yes. Clone the repo, install requirements.txt and run python desktop_main.py. Steps for the installer are in packaging/BUILD_INSTALLER.md.
